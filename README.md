# 🎓 Бот расписания СПК

VK-бот, который следит за изменениями расписания Сургутского
политехнического колледжа и присылает уведомления в беседу группы.

Умеет:
- следить за расписанием вашей группы в автоматическом режиме;
- присылать короткие уведомления об изменениях (замена преподавателя,
  кабинета, отмена пары, дистант);
- при массовых изменениях — присылать полное расписание дня или всей недели;
- автоматически отправлять расписание следующей недели, как только
  колледж его выложит;
- работать автономно 24/7 в облаке.

## Как это работает

Бот обращается к двум эндпоинтам сайта колледжа:

- `/api/schedule/index` — справочники (группы, преподаватели,
  дисциплины, аудитории);
- `/api/schedule/schedule?date=<timestamp>` — расписание на дату.

Справочники кэшируются в SQLite на сутки. Расписание проверяется
по расписанию окон (см. [Расписание проверок](#расписание-проверок)),
сравнивается с предыдущим снимком в БД. Если что-то изменилось —
формируется сообщение и отправляется в беседу ВК.

## Архитектура

Проект разбит на модули, каждый отвечает за своё:

| Файл | Ответственность |
|---|---|
| `lesson_times.py` | Расчёт времени пар по дню недели. API колледжа не отдаёт время — считаем сами: Пн сдвинут на 30 мин, Сб пары по часу, Вс — выходной. |
| `schedule_api.py` | Клиент API колледжа. Единственное место, которое знает про HTTP, URL и JSON. Ретраи, таймауты, нормализация, поиск группы. |
| `database.py` | SQLite: настройки, снимки расписания, объявленные недели, кэш справочников, лог уведомлений. WAL-режим, потокобезопасность. |
| `comparator.py` | Сравнение двух снимков. Список изменений, определение «массовости» (когда слать полное расписание). |
| `formatter.py` | Формирование текстов: расписание дня, недели, короткий diff, полное расписание при массовых изменениях. |
| `scheduler.py` | Планировщик: когда и что проверять. Логика окон по дням недели, объявление недели, группировка изменений. |
| `handlers.py` | Команды бота: `/start`, `/group`, `/today` и т.д. Проверка прав админа. |
| `config.py` | Загрузка переменных окружения из `.env`. Список админов. |
| `bot.py` | Точка входа: long-polling ВК + фоновый цикл проверки в одном asyncio-loop. Приветствие при первом запуске. |

## Установка

### 1. Создайте сообщество ВК

1. Откройте https://vk.com/groups и создайте сообщество (тип — любой).
2. Управление → Работа с API → Создать ключ.
3. Дайте права: **«Управление сообществом»** и **«Сообщения сообщества»**.
4. Включите **Long Poll API** в той же вкладке.
5. В **«Типы событий»** отметьте **«Входящие сообщения»**.
6. Скопируйте токен вида `vk1.a.xxxxxx`.
